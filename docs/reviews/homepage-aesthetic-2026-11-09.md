# 主页审美调整 · 2026-11-09

状态：2026-11-09 立正看过改前改后的截图（逐章对比、手机前六屏、全页对比、「立正」大字两种颜色）后回复「改吧 上线吧」，同日上线。

## 起因

立正让 Claude 看主页有什么可以改进，「审美的取舍上可以大胆一点」。他要的四件事：让人觉得惊艳、看着舒服、愿意看下去、对他的能力有很大的信任。

## 这页是干什么的

来的人多半看过他的视频、搜过他的名字，或被人介绍来（10-29 的访客数据）。主页要做两件事：让人很快知道他是谁、相信什么、凭什么信；把想深入的人带进超线性学院。对很多访客，页面本身做得好不好，就是他能力的一部分证据。

## 改之前的问题

内容是对的，取舍也经过好几轮（9-30、10-12、10-29）。问题在版面：

1. **整页音量差不多。** 首屏之后十章，每章都是「小标题＋大标题＋右边一段灰字＋内容」，一样的间距、一样的分量，没有哪里让人停一下。真正别处没有的东西，那座每盏灯都是真人的城，被装在一个带边框的小窗里。
2. **证据印得太小。** 清华讲席教授、OpenAI应用CTO、真格合伙人、IHG高级副总裁的评价，是整页最能让人信他的东西，却各只有截短的一句、15到17px，结尾是省略号。现场照片是四张一样大的小图，还在滚动，没法好好看。
3. **零碎的装饰多。** 三种深浅的米色来回换；圆角卡片、阴影、绿色标签、时间线的圆点；每一块滑到时都要「浮上来」，照片和名字各有一条在滚。单看都不过分，加在一起就是立正说过的「busy」，也像模板。
4. **首屏没撑满。** 人像装在文字栏里的一个格子内，宽屏上显小；首屏不到一屏，底下露出一截下一段。

## 方向

**两处让人停下来，中间安静。** 首屏和那座城是整页的两个高潮，其余都往后退：同一张纸、同一种线，把字和照片放大，不靠装饰。沿用 10-03 定下的原则（纸色、墨色、细线；品牌绿只给能点的；不用卡片和阴影堆结构），这次是把它做到底。

## 改了什么，为什么

| 位置 | 原来 | 现在 | 为什么 |
| --- | --- | --- | --- |
| 首屏 | 不到一屏；人像在格子里；「立正」大字奶白 | 首屏加履历条正好一屏；标题更大；人像和大字铺到窗口右边；大字是绿色 | 第一眼要像一张海报。奶白大字和奶白标题是两块一样亮的东西，白T恤还和大字混在一起；改成绿色后，最亮的只有标题，人从大字前面站出来 |
| 同行评价 | 四条截短的一句，结尾省略号 | 四条完整原话，标题字体，两行两列；署名旁写在评价什么 | 这是最强的信任证据，要当成话来读，不是当图注扫过去。原话是关于页已有的那四条 |
| 现场照片 | 四张小图滚动 | 一大三小，不动 | 一张满场的大照片比四张小图有说服力；不动才能看 |
| 城 | 带边框的小窗，在四项文字下面 | 夜色里铺满整屏，没有边框；四项文字在城下面 | 这是别人没有的东西，应该是第二个高潮 |
| 问答、对话、书、判断、文章 | 三种米色来回换 | 同一张纸，章之间一条墨线 | 读的部分要安静，像一本书的几章 |
| 书 | 三张圆角卡片 | 一个书架，封面立在一条线上 | 书是实物，让它像实物；去掉卡片 |
| 公开判断 | 竖线、圆点、两张阴影卡片、绿色标签 | 一本账：日期、判断、原始记录三栏 | 「先写下来再让时间检验」本来就是账本，日期一栏已经说明了先后 |
| 嘉宾名字 | 一条在滚 | 静止两行 | 页面不自己动 |
| 加入 | 一张奶白大卡片加两个描边框 | 三栏、细线隔开，一个实心按钮 | 去掉盒子；这一章只有一个主要动作 |
| 结尾 | 居中大字 | 靠左大字，右边绿色「立正」签名 | 和首屏呼应；居中大字加两个按钮是最常见的模板结尾 |
| 动效 | 每块滑到时浮上来；两条滚动 | 只有首屏进场和那座城会动 | 动的东西少，城才显得是活的 |

## 没改的

- 各章的顺序和文字（10-12、10-29、10-30 定的）。
- 顶部导航、页脚、其他页面；city.lizheng.ai 和它单独的窗。
- 首屏文字和人像上下居中（10-12）；一章尽量一屏；按钮只有三种。
- 分享图 `/og/home-*.jpg` 还是奶白大字那张。上线后如果保留绿色大字，可以重截一张。

## 立正看过之后

1. 「立正」大字的颜色：上线的是绿色。他先问了一句「绿色的立正有必要吗？」，随后说上线，没有要求改回。绿色的理由见上表（最亮的只剩标题，人从大字前面站出来）；它不是非改不可，奶白更抢眼、也是用了一个多月的样子。以后如果要改回奶白，只改首屏那一处（`home.css` 里 `.hero-art .mark` 的颜色，一行）；结尾的签名在纸色底上，仍用绿色。
2. 首屏人像：原图只有 900 像素高，在大的高清屏上略软（现在最多放到 690px）。易拉宝那套有 5000 像素的照片；换不换是他的形象，这次没提，先不换。
3. 分享图 `/og/home-*.jpg` 没换，等大字颜色不再变了再重截。

## 验证

- `pnpm check`、三组测试（问问立正 547 项、嘉宾 35 项、课件 21 项）和 `pnpm build` 通过；预渲染的 `/` 和 `/en` 含全部正文，浏览器里没有报错。
- 逐屏看过：1440×900、1920×1080、1280×720、1024×768、1536×864、2560×1300、820（平板竖屏）、390 和 320（手机），中英文。320 到 1280 宽没有横向溢出，标题没有落单的字。
- 实际操作过：导航跳到各章、展开和收起另外三条判断、在提问框里打字（字是墨色）、在城里指向一盏灯、随机遇见 60 位成员（名片都在画面内，不压搜索框；电脑和手机）、按名字搜索、点评价里的名字打开嘉宾页。
- 版面用的都是固定长度，不依赖「拉伸后的百分比高度」、容器单位或 subgrid（加入一章有 subgrid 时用它对齐，没有时照样排得开），所以不同浏览器排出来一样。本机只有 Chromium，Safari 没有实测。

## 子页面（2026-11-09 晚，第二轮）

状态：2026-11-09 立正看过四页改前改后的对比图（电脑四张、手机一张）后回复「上线」，同日上线。

主页上线后，立正问：书、city、deck 这些子页面要不要一起改。逐个看过（电脑和手机），按「和新主页放在一起像不像同一个网站」来分：

### 改了的四页

导航「更多」里的四个页面。它们是 9-30 那一版的样子：圆角卡片、灰色标签、带图标的按钮、小号全大写的英文标签，演讲资料和关于还是深色底。新主页刚把这些去掉，从主页点过去落差最大。正文、事实、链接都没动，只重排版面；动了的小字只有：演讲资料页的小标题改成和导航一致的「演讲资料」（原来是「课代表立正 · 企业AI DECKS · 2026」）、它首屏的「查看全部课件」按钮去掉（目录就在下面）、合作页和演讲资料页里不表示先后的 01、02、03 编号去掉、英文小标题从全大写改成普通大小写。

| 页面 | 原来 | 现在 |
| --- | --- | --- |
| 书 `/books` | 三张圆角卡片（新书占一整行），灰色标签，带图标的按钮，绿底的会员提示框 | 主页书架的完整版：封面立在一条墨线上；线下是每本书回答的问题、简介、出版信息和按钮；会员提示是书架下的一行小字 |
| 演讲资料 `/decks` | 深色底；每套一张卡片，封面是程序画的装饰图；胶囊筛选按钮 | 纸色目录，每套一行：给谁讲的和日期、标题和内容、打开方式；有网页版的放它真实的第一页；搜索加两排文字标签 |
| 合作 `/collab` | 三张带图标的卡片、绿底说明框、两块绿色大色块 | 细线隔开的三栏、一行说明、带照片的一行、左标题右内容的两章 |
| 关于 `/about` | 深色底上的格子（四项事实、四个项目、三个数字），小号全大写标签，带图标的按钮 | 森林绿的开头加履历条，下面是纸色的传记：左边章名、右边内容 |

做法：四页的根元素同时带 `.lz-home` 和 `.lz-sub`，所以按钮、文字链接、书架、细线用的就是主页那一份样式，不是照抄一份；子页面自己需要的（页头、目录行、三栏、左右两栏）在 `client/src/components/site/subpages.css`。因为共用 `.lz-home`，新起的类名不能和主页已有的撞（这次撞过两个：`.names` 是主页嘉宾名单、`.field` 是城的画框）。

课件目录的缩略图取自 `client/public/deck-slides/<网页版目录>/01.webp`（网页版本来就有的图）；`tests/deck-pages.test.ts` 加了一条，保证每个网页版的第一页都叫 `01.webp`。

### 没改的

- **city.lizheng.ai**：不用改。它本来就是整屏的夜景，是全站最好看的一页；主页那座城这次是向它看齐。
- **嘉宾目录和嘉宾页**：10-11 按同一套原则重做过（森林绿页头、纸色、细线）。
- **书的中文版、Statsig 文章、课件网页版**：都是用来读的静态页，森林绿页头加纸色正文，已经一致。
- **产品与资料指南 `/for-agents`**：给人和 AI 查资料用的页面，纸色加细线，够用。
- **企业培训 `/collab/enterprise`、播客与创作者邀请 `/collab/creators`**：建议下一轮改。它们已经是森林绿页头加纸色、价格阶梯用细线分行，问题比上面四页小，剩下的是小号大写标签、按钮里的图标和几个框。这两页是给要做决定的人逐条看的长页面，有价格和案例数字，每一块都调过；先让立正看过这四页、确认方向，再用同样的写法改它们。
- **《真本事》`/zbs`、播客 `/podcast`、嘉宾邀请 `/speaker`**：三个独立的页面，各有自己的地址和读者，用的是更早的一套深蓝黑设计（卡片、渐变）。和现在的主站不是一个样子，但每一页都要整页重做，不是换个样式的事。建议先做 `/zbs`：主页和书页的「了解这本书」都通到它，是访客最常走到的一处落差；另外两页排在后面。
