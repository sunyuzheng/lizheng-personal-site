# lizheng.ai内容系统

本文档说明个人网站各页面的任务、事实来源与更新边界，避免个人品牌、Superlinear产品站和GitHub之间重复或漂移。

## 一条主线

个人主页只争取留下一件事：

> **MAKE WHAT LASTS.**
>
> **做出你的代表作。**

这既是Superlinear Academy的品牌主张，也是立正的个人母题。不是“立正还有一套个人观点，Superlinear另有一个slogan”，而是立正选择站在这件事后面，Superlinear是他用来实践并放大它的长期机构。

`Make what lasts`不是永恒、爆红或规模化的保证；`做出你的代表作`也不是一项课程交付承诺。它们共同指向一种标准：选择值得投入的事，以判断和手艺把它做到成立，让现实检验，并在值得时让有效部分继续工作。作品可以是产品、研究、内容、组织、手艺、工具或系统；不要求所有有价值的劳动都变成资产。

首页不再陈列一组平行的“思想家命题”。它只保留一条紧凑的实践循环：

> **看准 → 做成 → 交给现实 → 留下**

这不是固定流水线：行动会改变问题，现实会迫使人重做，留下来的东西也会老化。它描述立正的实践纪律，不冒充普遍规律。

## 首页的阅读顺序

1. **先记住主张。** Hero直接使用中英文母句，并建立立正与Superlinear的关系。
2. **理解它反对什么。** AI让很多数字工作的第一版更便宜；真正稀缺的仍是判断、手艺、作者性，以及完成后仍继续创造价值的作品。
3. **看这套标准怎样形成。** 康奈尔、Amazon、Meta、腾讯、Statsig和Superlinear被写成一段逐步形成的经历，而不是logo墙。
4. **看一条可检查的判断。** 主页只保留2023年2月、GPT-4发布前的ChatGPT文章作为代表记录。
5. **看主张怎样成为机构。** 免费社区、AI Builders、会员和企业实践各自承担不同任务。
6. **由一手对话、书与第三方评价补足证据。** 它们服务同一个人物印象，不再形成并列栏目清单。
7. **把行动交还给访问者。** 访问者可以免费进入社区、了解AI Builders或与立正合作。

详细页面结构见`docs/homepage-narrative-outline.md`。

## 哪些命题不再与母题并列

以下内容仍可能有价值，但必须按类型归位，不能再次堆回首页或个人品牌宪法：

| 表达                         | 正确类型与位置                                                           |
| ---------------------------- | ------------------------------------------------------------------------ |
| 世界模型                     | 帮助“看准”的一种判断工具；不是独立品牌支柱                               |
| Strong opinions, weakly held | 特定表达与讨论方法；更准确地说，观点要具体到可被挑战，证据可以改变它     |
| AI让执行变便宜、瓶颈上移     | 带日期、带范围的AI时代判断；不作为永恒规律                               |
| User → Builder → Architect   | 部分学习者的产品训练路径；不是人的价值等级，也不是普遍成长阶梯           |
| 用计算换认知                 | 低风险、可隔离、可验证场景下的AI-native启发式；不是普遍法则              |
| 复利来自系统                 | 产品设计偏好；系统会折旧，也会放大错误，并非所有有价值的工作都需要资产化 |
| 分发与叙事                   | 需要被采用的作品的界面；不能替代作品价值本身                             |
| 企业AI四层模型               | 当前企业项目的诊断框架；不属于个人永恒哲学                               |

长期信念、实践原则、阶段性判断、产品目的与事实必须使用不同强度的语言。个人思想owner中的`DATED_VIEWS.md`保存会更新的判断；具体产品框架回到各自owner。

## 权威如何出现

首页遵循`show → frame → let the reader conclude`：

1. **每条证据只回答一个问题。** 3,000+与Maven评分回答教学采用与满意度；DoorDash现场回答方法能否进入真实组织；200+场对话回答一手输入从哪里来。
2. **证据放在问题发生处。** 学员数字跟着AI Builders，社区行为跟着免费社区，WSJ书单跟着书。
3. **解释必要的一步。** 让非专业读者明白鸭哥的论文发表于AI顶会；不把每个事实都解释成“所以我们厉害”。
4. **保留真正重要的边界。** 雇主不是个人背书，流量不是观点正确，公开判断也不等于永远看得准，产品目的不等于保证成员结果。

- 母句固定为`做出你的代表作。`
- 付费产品第一次出现写`Stay Superlinear会员`，后文写`会员`。

## GitHub的任务

GitHub不复制整页人物宣言。它回答一个更窄的问题：这个人公开做出了什么，愿意把哪些系统交给别人使用？

Profile README只需要一句身份、当前工作、精选公共项目、书与公开内容入口、Seattle和联系方式。置顶仓库优先选择真实可用、边界清楚、README完整的工具，不按stars机械排序。

## 发布前检查

1. 新数字是否已经进入`yuzheng-profile/facts.json`并附`as_of`与证据。
2. 是否误把Statsig被OpenAI收购写成孙煜征加入OpenAI。
3. 是否混淆免费Superlinear Academy与付费会员。
4. 是否把对话场次写成嘉宾人数。
5. 是否使用`stay.superlinear.academy`、`ai-builders.com`和`www.lizheng.ai`。
6. 页面title、description、canonical、OG、sitemap与正文是否一致。
7. 核心页源HTML是否包含真实正文，中英文页是否reciprocal hreflang。
8. sitemap `lastmod`是否只反映真实内容变更。
9. `pnpm check`与`pnpm build`是否通过。
10. 公开部署、GitHub推送或客户可见修改是否展示过精确diff并获得针对该payload与destination的批准。
