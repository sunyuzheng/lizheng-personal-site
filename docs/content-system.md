# lizheng.ai内容系统

本文档说明个人网站各页面的任务、事实来源与更新边界，避免个人品牌、Superlinear产品站和GitHub之间重复或漂移。

## 一条主线

个人主页只争取留下一件事：

> **MAKE WHAT LASTS.**
>
> **做出你的代表作。**

这既是Superlinear Academy的品牌主张，也是立正的个人母题。不是“立正还有一套个人观点，Superlinear另有一个slogan”，而是立正选择站在这件事后面，Superlinear是他用来实践并放大它的长期机构。

`Make what lasts`不是永恒、爆红、无人维护或规模化的保证；`做出你的代表作`也不是一项课程交付承诺。它们共同指向一种标准：把逐渐挣来的理解与手艺，做成作者愿意长期负责、价值又能超越制作或首次发布当下的作品。作品可以是产品、研究、内容、组织、手艺、工具、表演或系统；不要求所有有价值的劳动都变成资产。

首页不再陈列一组平行的“思想家命题”，也不在母题下面发明一条整齐的成功流程。它呈现一组性质不同、彼此作用的思想关系：

- 世界模型、预测与证伪，尽力让更多理解变得显性、可挑战；
- craft在规则无法完整压缩、却仍需对结果负责的复杂性中继续更新同一份理解；两者彼此渗透和修正；
- `understand → internalize → conviction → build`解释理解在需要下注时怎样进入行动；
- 负责任的作者性，让作品的目的、标准、取舍与后果始终有人承担；
- 现实持续检验，时间逐渐显露什么继续重要，但两者都不是无误的终审。

代表作也不总从conviction开始。人可能先进入迷雾、动手并失败，再从预期与结果的差距里逐渐知道自己相信什么。这种非线性是整个解释成立的重要部分，但不是又一根品牌支柱。系统、制度、维护和分发可能是输入、craft的一部分或作品本身；复利才是可能结果。

## 首页的阅读顺序

1. **先记住主张。** Hero直接使用中英文母句，并建立立正与Superlinear的关系。
2. **先抬高欲望与标准。** 从“一个人可以很能干，却没有一件工作真正属于自己”进入，再用乔布斯与张小龙的产品、梅西的足球、诺兰的电影、Hinton与巴菲特经受时间的判断、西冈常一的宫殿木作，让读者感受作品与人最终无法分开的高度。不把人物分类成咨询式的美德卡片。
3. **理解它在AI时代反对什么。** 第一版正在泛滥；发现、标准、手艺、作者性与人们继续选择的作品并没有因此变多。
4. **看这份下注为什么真实。** 康奈尔、Amazon、Meta、腾讯、Statsig与一次离开清晰晋升路径的选择，只证明立正的真诚、代价与现实能力，不替理念自证。
5. **看一条可检查的判断。** 主页只保留2023年2月、GPT-4发布前的ChatGPT文章作为代表记录。
6. **看主张怎样进入机构。** Superlinear被写成立正选择长期建设的学院，而不是已经完成的代表作；免费社区、AI Builders、会员与企业实践分别承担不同任务。
7. **由一手对话、书与第三方评价补足证据。** 它们让访客从立正长期选择、学习和完成的工作中形成判断。
8. **把行动交还给访问者。** 访问者可以免费进入社区、了解AI Builders或与立正合作。

详细页面结构见`docs/homepage-narrative-outline.md`。

立正不是母品牌之外的“代言人”。他为这套信念命名、持续阐释，也把自己的工作放在同一条标准之下；Superlinear是他正在押注的最重要长期作品，也是让更多人有机会追求自己代表作的制度载体。它最终能否成为代表作，不由创始人预先颁发。

## 哪些命题不再与母题并列

以下内容仍可能有价值，但必须按类型归位，不能再次堆回首页或个人品牌宪法：

| 表达                         | 正确类型与位置                                                           |
| ---------------------------- | ------------------------------------------------------------------------ |
| 世界模型                     | 努力把理解外显并接受证伪；与craft彼此渗透和修正，但不是另一条公共口号   |
| Strong opinions, weakly held | 让conviction仍可被证据改变的一条纪律；不是人格标签或普遍步骤             |
| AI让执行变便宜、瓶颈上移     | 带日期、带范围的AI时代判断；不作为永恒规律                               |
| User → Builder → Architect   | 部分学习者的产品训练路径；不是人的价值等级，也不是普遍成长阶梯           |
| 用计算换认知                 | 低风险、可隔离、可验证场景下的AI-native启发式；不是普遍法则              |
| 复利来自系统                 | 产品设计偏好；系统会折旧，也会放大错误，并非所有有价值的工作都需要资产化 |
| 分发与叙事                   | 需要被采用的作品的界面；不能替代作品价值本身                             |
| 企业AI四层模型               | 当前企业项目的诊断框架；不属于个人永恒哲学                               |

长期信念、实践原则、阶段性判断、产品目的与事实必须使用不同强度的语言。个人思想owner中的`DATED_VIEWS.md`保存会更新的判断；具体产品框架回到各自owner。

## 权威如何出现

首页遵循`show → frame → let the reader conclude`：

1. **伟人与杰作定义地平线。** 他们不为立正或Superlinear背书；品牌对他们的选择与解释，让访客看见立正认得怎样的作品。
2. **个人经历证明真诚、下注与能力。** 它们不把创始人提前放进伟人的成就序列。
3. **产品与数字建立当下可信度。** 3,000+与Maven评分回答教学采用与满意度；DoorDash现场回答工作能否进入真实组织；200+场对话回答一手输入与网络从哪里来。
4. **证据放在问题发生处。** 学员数字跟着AI Builders，社区行为跟着免费社区，WSJ书单跟着书。
5. **解释必要的一步。** 让非专业读者明白鸭哥的论文发表于AI顶会；不把每个事实都解释成“所以我们厉害”。
6. **作品与时间保留最终判决。** 雇主不是个人背书，流量不是观点正确，公开判断也不等于永远看得准，产品目的不等于保证成员结果。

### 播客与视频访谈资料

- `/zh/collab/creators`是中文节目邀请与host kit的线上canonical：案例、合作方式、可聊方向、bio、头像、事实链接与联系入口都从这里维护。
- `/collab/podcast-kit-zh.pdf`是可下载、可转发的六页离线资料：它用经历建立判断背景，用Koji与屠龙两个跨平台案例证明合作内容可以成立，再给主持人可直接采用的选题与录制信息。PDF不是删掉案例后的品牌宣言。
- `scripts/generate-podcast-collab-pdf.py`是PDF生成源；修改事实、案例、链接或版式后，需要重新生成并逐页渲染检查。
- 旧地址`/collab/podcast-one-pager.pdf`永久跳转到当前六页资料，避免外部旧链接失效。

## GitHub的任务

GitHub不复制整页人物宣言。它回答一个更窄的问题：这个人公开做出了什么，愿意把哪些系统交给别人使用？

Profile README只需要一句身份、当前工作、精选公共项目、书与公开内容入口、Seattle和联系方式。置顶仓库优先选择真实可用、边界清楚、README完整的工具，不按stars机械排序。

## 发布前检查

1. 新数字是否已经进入`yuzheng-profile/facts.json`并附`as_of`与证据。
2. 是否误把Statsig被OpenAI收购写成孙煜征加入OpenAI。
3. 是否混淆免费Superlinear Academy与付费会员。
4. 是否把对话场次写成嘉宾人数。
5. 是否使用`stay.superlinear.academy`、`ai-builders.com`和`www.lizheng.ai`。
6. 页面title、description、canonical、OG、sitemap与正文是否一致。
7. 核心页源HTML是否包含真实正文，中英文页是否reciprocal hreflang。
8. sitemap `lastmod`是否只反映真实内容变更。
9. `pnpm check`与`pnpm build`是否通过。
10. 公开部署、GitHub推送或客户可见修改是否展示过精确diff并获得针对该payload与destination的批准。
